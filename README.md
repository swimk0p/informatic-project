# hotcoffe-now
### *hotcoffe-now -- программа для Учёта заказов в кафе*

## **цель системы** 
### управление и распределение заказов, сбор статистики заказов и пользователей

**будет учитывать:** 
- заказчика
- название заказанного продукта
- цена/количество
- рецепт
- статус заказа
- дата

**пользователи:** 
- официанты
- повар/шеф
- управляющий/админ


# **польза со стороны пользователей и функции:**

- со стороны официанта -  создание нового заказа и его редактирования, отслеживание статуса заказа, выдача готового заказа.

- со стороны шефа/повара - получение заказа на кухне, изменение статуса на "готово для выдачи".

- со стороны Управляющего - удобное состовление отчета о продажах и тратах, а также сбор статистики о работниках(скорость, количество сделанных заказов и т.д и т.п).
